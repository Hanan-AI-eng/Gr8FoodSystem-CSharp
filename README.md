# 🍽️ Gr8FoodSystem

Gr8FoodSystem is a C# Windows Forms restaurant management system developed as a university project.

The system provides different functionalities for customers, chefs, managers, and administrators to manage restaurant operations.

## 📌 Features

### 👤 Customer
- Customer login and registration
- Browse menu items
- Place and view orders
- View order history
- Manage customer wallet
- Submit feedback
- Update profile

### 👨‍🍳 Chef
- Chef dashboard
- View and manage food items
- Manage menu-related information

### 👨‍💼 Manager
- Manager dashboard
- Manage restaurant menu
- Manage users
- View customer feedback
- View sales reports
- View wallet reports
- Update profile

### 🔐 Administrator
- Admin dashboard
- Manage system users
- Manage restaurant information

## 🛠️ Technologies Used

- **C#**
- **Windows Forms**
- **.NET**
- **Visual Studio**
- **SQL Database**
- **Git & GitHub**
